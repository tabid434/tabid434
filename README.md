## This repository

The site is a Next.js app. Project copy lives in `src/lib/portfolio.ts`.

```sh
npm install
npm run dev
```

Open the URL Next.js prints. The default is http://localhost:3000.

```sh
npm run lint
npm run build
npx playwright install chromium
npm test
```

Playwright runs an isolated production server on port 3100. Tests do not send real email.

### Email and environment

`POST /api/contact` sends a plain-text message through Resend to `talhaabid353@gmail.com`, with the visitor’s address as Reply-To. Credentials stay on the server. The endpoint fails closed when email or the shared rate limiter is missing.

Copy `.env.example` to `.env.local` and set:

| Variable | Purpose |
| --- | --- |
| `SITE_URL` | Deployed origin. Also used for canonical URLs and the sitemap. |
| `RESEND_API_KEY` | Resend key with sending permission. |
| `CONTACT_FROM_EMAIL` | Sender on a verified Resend domain. |
| `UPSTASH_REDIS_REST_URL` | Upstash Redis REST endpoint for rate limiting. |
| `UPSTASH_REDIS_REST_TOKEN` | Upstash Redis REST token. |

Deploy to a Node-capable Next.js host. The contact route validates origin, content type, body size, and field length, uses a honeypot, and limits submissions to five messages per ten minutes.
